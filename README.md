# obni-calendar
Конструктор расписания и визуальный редактор украшений. Публикация - GitHub Pages, ветка `main`, корневая папка.

- `index.html` - существующая логика встреч и экспорт PNG 1080 × 1350.
- `design.js`, `design.css` - украшения, слои, жесты, история, шаблоны и копии дизайна.
- `index-before-design-2026-11-11.html` - резервная версия 1.1 до визуального редактора.
- `design-preview.html` - страница для предварительной проверки редактора.

Черновики хранятся только в браузере. Старый ключ встреч `obni_schedule_v1` сохранен. Оформление и свои изображения хранятся отдельно в `obni_design_v1`. Перенос между устройствами - через JSON-копию. Восстановление сначала проверяет копию целиком, запрашивает подтверждение замены совпадающих месяцев и скачивает предыдущие данные. Старые копии, содержащие только встречи, поддерживаются.

В режиме «Дизайн»: один палец двигает выбранное украшение; два пальца меняют масштаб и поворот. Есть отдельные ручки, ползунки и поля координат. Карточки встреч закреплены. PNG и SVG загружаются локально; SVG проверяются на внешние ресурсы и исполняемый код. Для собственного SVG нужны размер или `viewBox`.

Проверки логики: `npm install`, затем `npm test`. Тесты проверяют встречи, историю, блокировки, шаблоны, переключение месяцев, перетаскивание и жест двумя указателями, импорт SVG и восстановление копий. Они не заменяют визуальную проверку и проверку в Safari на физическом iPhone/iPad.


Версия 3: вкладка «Дизайн → Оформление». Модуль `appearance.js` применяет стили к семантическим слоям SVG, не изменяя встречи и позиции украшений. Есть семь палитр, отдельные цвета элементов, градиент до восьми цветов, локальные фоновые изображения PNG/JPG/WebP, системная кириллическая типографика и библиотека своих цветовых тем.

Настройки входят в `appearance` каждого месяца. Фоновые изображения хранятся один раз в `backgrounds`, именованные цветовые темы - в `colorThemes` внутри существующего `obni_design_v1`. Старые черновики и JSON-копии мигрируют без удаления встреч и украшений. Шаблоны оформления и полные копии включают новые настройки. При восстановлении конфликтующие изображения получают новые идентификаторы, существующие ресурсы остаются.

Резервная копия до версии 3: `obni-before-appearance-2026-11-11.zip`. Архив содержит полную предыдущую версию сайта. Для восстановления следует извлечь его файлы в корневую папку репозитория.

`npm test` выполняет обе группы проверок: прежний редактор украшений и новый редактор оформления, включая сохранность старых данных при применении тем, градиенты, шрифты, фон под карточками, перемещение фона, библиотеку цветовых тем, отмену/повтор и восстановление копий. Проверку Safari на физическом iPad/iPhone нужно проводить отдельно.
